# Protobot Rebuilt V2, v2.0 Beta 1 (build 76)

**Bug fixes.**

- Save and Open file dialogs now come to the front in full-screen mode instead of opening behind the window.
- Zooming, panning and turning the view while sketching on a part now use your Preferences camera speeds, so the view no longer jumps out of control.
- On PCs set to a language that writes decimals with a comma (German, French, Turkish...), the camera moved, zoomed and turned far too fast and some sizes (like shaft lengths) were read wrong: numbers are now read the same way on every PC.
